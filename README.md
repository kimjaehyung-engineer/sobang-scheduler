# 🔥 소방마스터 60일 완주 & 에빙하우스 망각방지 플래너 (FireMaster Coach)

> **"기술사 합격률 1~3%. 오늘 미룬 20페이지는 내일의 불합격 통지서입니다."**  
> 방대한 소방기술사 수험서 **'소방마스터'**를 2개월(60일) 만에 1회독 완파하고, 에빙하우스 망각곡선 누적 복습으로 완벽하게 머릿속에 각인시키는 전용 웹 애플리케이션입니다.

---

## 🌟 주요 핵심 기능

### 1. 60일 동적 페이싱 엔진 (Dynamic Pacing)
- **자동 진도 계산**: `(잔여 페이지 / 잔여 일수)`를 매일 실시간 자동 계산하여 당일 읽어야 할 추천 페이지 범위(예: `p.145 ~ p.168`)를 제시합니다.
- **학습 편차 자동 보정**: 어제 공부를 많이 했거나 부득이하게 적게 했더라도, 목표 기간 내에 완주할 수 있도록 매일 목표 페이지를 유연하게 재조정합니다.
- **계획선 대비 진도 진단**: 계획 대비 며칠 앞서가고 있는지, 혹은 지연되었는지 실시간 피드백을 제공합니다.

### 2. 에빙하우스 망각곡선 5단계 누적복습 큐 (Spaced Repetition)
오늘 새로운 진도를 기록하면, 뇌과학 망각곡선에 따라 자동으로 **5단계 복습 스케줄**이 생성됩니다:
1. **1차 복습 (+1일 후 / 내일)**: 단기 기억에서 장기 기억으로 전환 (가장 중요)
2. **2차 복습 (+3일 후)**: 핵심 키워드 및 목차 인출 훈련
3. **3차 복습 (+7일 후)**: 1주일 누적 종합 및 화재안전기준 점검
4. **4차 복습 (+14일 후)**: 기출문제 연계 및 2~4교시 서술형 구조화
5. **5차 복습 (+30일 후)**: 시험장까지 가져가는 영구 기억 정착
- 대시보드에서 오늘 복습할 구간을 원클릭으로 체크(`복습 완료`)할 수 있으며 축하 콘페티 효과가 발생합니다.

### 3. 의지박약 타파! 3대 코칭 모드 (Fact Bomb & Motivation)
- 🔥 **팩트폭행 모드**: "기술사 면접관 앞에서 어버버할 겁니까? 지금 책 펴세요!" 등 나태함을 깨우는 충격요법
- 🛡️ **멘토 코칭 모드**: 합격 선배들의 실전 서브노트 작성 요령 및 암기 인출 전략 가이드
- 🌱 **따뜻한 격려 모드**: 퇴근 후 지친 수험생의 페이스메이커 역할을 하는 따뜻한 위로와 격려
- **새 자극 버튼**: 언제든 상단 배너를 클릭하여 새로운 자극 문구를 불러올 수 있습니다.

### 4. 소방기술사 맞춤형 포모도로 타이머
- **50분 집중 / 10분 휴식**: 실제 기술사 시험 1교시(100분) 감각을 기르기 위한 50분 집중 세션
- **25분 단기 암기 모드**: 이동 중이거나 짧은 시간 동안 서브노트 1단원 암기 모드
- 종료 시 Web Audio 비프음 및 콘페티 알림

### 5. 완벽한 데이터 안전성 & 100% 로컬 프라이버시
- 모든 학습 기록 및 설정은 브라우저의 `LocalStorage`에 영구 자동 저장됩니다.
- 외부 서버나 회원가입이 필요 없으며, **[데이터 백업]** 및 **[데이터 복원]** 버튼을 통해 언제든 JSON 파일로 다운로드하고 다른 PC나 스마트폰으로 옮겨올 수 있습니다.

## 🚀 실행 방법

### 방법 1: 더블 클릭으로 바로 실행
- 폴더 내의 `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 사파리(Safari) 등 웹 브라우저로 즉시 열어서 사용하시면 됩니다.

### 방법 2: 로컬 웹 서버로 열기 (권장)
VS Code의 `Live Server` 익스텐션을 사용하거나 터미널에서 다음을 실행합니다:
```bash
npx serve .
# 또는
python -m http.server 8080
```
브라우저에서 `http://localhost:8080` 접속

## 📱 스마트폰(모바일) 홈 화면에 추가하여 앱처럼 쓰기
1. 스마트폰 브라우저(Safari 또는 Chrome)에서 해당 주소를 엽니다.
2. 브라우저 설정에서 **'홈 화면에 추가'**를 누르면 스마트폰 전용 앱처럼 전체 화면으로 매일 출퇴근길에 진도를 확인하고 복습할 수 있습니다.
